Cookies & Browser Storage

Last updated: 30 October 2026

UFLMB aims to use only the browser storage needed to operate the service and remember your preferences. It does not use advertising cookies or cross-site advertising trackers.

Current implementation: the application uses localStorage and sessionStorage for interface preferences and sign-in session state. These are browser storage mechanisms; they are not necessarily HTTP cookies.

Storage used by the application

CategoryPurposeStorage
Theme preferenceRemember dark, light or system appearance.localStorage
Interface preferencesRemember selected page, browse filters, favourites/comparison state and other convenience settings.localStorage
Authentication sessionKeep the current sign-in session available for the active browser tab/session.sessionStorage
Temporary admin stateRemember the selected admin section and dashboard state during the browser session.sessionStorage

Storage keys and exact values may change as the application evolves. Clearing site data in your browser removes locally stored preferences and may sign you out. Shared account and community data stored by the service provider is not deleted by clearing browser storage.

Analytics

UFLMB has an optional integration point for Cloudflare Web Analytics. It is inactive unless the site owner configures the relevant site beacon token in the deployment environment. Cloudflare describes Web Analytics as cookie-free and states that it does not collect or use visitors' personal data. Its documentation describes collection of navigation and page-performance timing metrics. The beacon is optional and is only loaded in the Firebase production build when the site-specific build variable is configured.

UFLMB does not use Google Analytics, advertising pixels, session replay or cross-site behavioural advertising trackers in the current implementation. If the analytics provider or configuration changes, this notice will be updated before activation.

Managing browser storage

You can view or clear website storage through your browser's site settings. Blocking all storage may affect sign-in and saved preferences. The exact controls vary by browser and device.

Contact

For questions about privacy or browser storage, contact UFLMB at uflmb.dev@gmail.com or through the in-site Support chat. See the Privacy Notice.
